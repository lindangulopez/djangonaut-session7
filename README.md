# Djangonaut Space, Session 7

What I am doing as a Djangonaut from 12 October to 6 December 2026: tutorials first, then the Django ORM and accessibility.

Site: https://lindangulopez.github.io/djangonaut-session7/

## Build locally

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/mkdocs serve
```

The pages are in `docs/`. A push to `main` rebuilds and publishes the site through GitHub Actions.
